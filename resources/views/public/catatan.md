# Catatan Dokumentasi: Folder Views Publik (`resources/views/public/`)

## 1. Apa Fungsi Folder Ini? (Bahasa Santai)
Folder ini berisi seluruh tampilan halaman depan yang **Bebas Diakses Siapapun Tanpa Login**! 🌐
Terdiri dari:
1. **Landing Page Promosi (`landing.blade.php`)**: Halaman depan penawaran jasa pembuatan website portofolio profesional untuk UMKM.
2. **Template Portofolio UMKM (`templates/`)**: 5 desain website yang otomatis terisi data profil dan produk masing-masing klien UMKM.

## 2. Bedah Halaman Landing Page (`landing.blade.php`)
Desain Landing Page ini menggunakan konsep **Clean Modern White Theme** yang sangat elegan, profesional, dan ramah pembaca.

### Komponen Keren di Landing Page:
1.  **Navbar**: Logo CMS Web Builder, menu navigasi, dan tombol Login Admin.
2.  **Hero Section**: Penawaran utama *"Solusi Web Portofolio UMKM Terima Beres dalam 24 Jam"*.
3.  **6 Fitur Unggulan**: Alamat slug unik, katalog produk dinamis, tombol pesan WA langsung, peta Google Maps, ramah HP, dan bebas biaya server.
4.  **Etalase Kategori Desain**: Menampilkan 5 pilihan tema (Minuman, Makanan, Toko Barang, Tokoh Publik, dan Jasa).
5.  **Paket Layanan**: Perbandingan paket Starter (3 Bulan) vs Pro Bisnis (1 Tahun).
6.  **Interactive CV Card Developer**: Kartu profil resmi Hanan Aria Santagama (Siswa SMKN 1 Majalengka, XII RPL 1, Tech Stack, dan kontak).
7.  **Lokasi Google Maps**: Peta lokasi SMKN 1 Majalengka.
